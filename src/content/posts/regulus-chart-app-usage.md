Regulus Chart (레귤러스 차트) 어플리케이션 사용방법에 대한 안내입니다.

---

## ✨ Regulus Chart란?

> **내담자의 출생 정보로 네이탈 차트를, 원하는 시점으로 트랜짓 차트를 그려주는 상담용 점성 도구**입니다.
>
> 모든 계산은 스위스 에페메리스(Swiss Ephemeris)를 기반으로 **휴대폰 안에서** 이루어집니다.
> 네트워크에 접속하지 않고, 내담자 정보는 **오직 이 기기에만** 저장됩니다.

---

### 1. 내담자 임상 기록 (첫 화면)

<img src="/assets/images/Contents/app-usages/R.png" width="250" style="display: block; margin: 0 auto; border-radius: 15px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);">
<br>

**주요 기능:**
*   **내담자 카드**: 이름, 생년월일·출생 도시, 그리고 한눈에 보는 요약 — **ASC(상승궁)**, **☉ 태양**(별자리·하우스), **☽ 달**(별자리·하우스) — 이 한 줄로 표시됩니다.
*   **검색**: 상단 검색창에 이름을 입력하면 내담자를 바로 찾을 수 있습니다.
*   **⋮ 메뉴**: 카드 오른쪽 점 세 개를 누르면 **수정 / 삭제** 를 할 수 있습니다.
*   **＋ 버튼**: 오른쪽 아래 버튼으로 신규 내담자를 등록합니다.

<br>

### 2. 신규 내담자 등록 · 수정

**입력 항목:**
*   **이름**
*   **생년월일 (양력)** — 년 / 월 / 일
*   **태어난 시간 (24시간제)** — 시 / 분. 시간을 모르면 **‘시간 알 수 없음’** 을 체크합니다. (이 경우 정오 기준으로 계산됩니다.)
*   **출생 도시** — 필드를 누르면 도시 검색창이 열립니다. **한글·영문 어느 쪽으로 입력해도** 검색되며(예: `서울`, `Seoul`, `대한민국`), 주요 국가의 대표 도시가 준비되어 있습니다. 기준 도시는 **대한민국 서울**입니다.

저장하면 곧바로 해당 내담자의 차트 화면으로 이동합니다. ⋮ 메뉴의 **수정**을 누르면 같은 화면에서 정보를 고쳐 다시 저장할 수 있습니다.

<br>

### 3. 차트 화면 — 네이탈 (N)

<img src="/assets/images/Contents/app-usages/R_chart.png" width="250" style="display: block; margin: 0 auto; border-radius: 15px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);">
<br>

**주요 기능:**
*   **차트 휠**: 12사인 · 플라시두스 하우스 · 행성 · 어스펙트를 손으로 그린 방식으로 표현합니다.
*   **어스펙트**: **행성↔행성**, **행성↔앵글(ASC/DSC/IC/MC)** 만 표시됩니다. 앵글끼리는 기하학적으로 고정된 관계라 표시하지 않습니다.
*   **시간 조절**: 화면 아래 **연 / 월 / 일 / 시 / 분** 버튼(`-5 · -1 · +1 · +5`)으로 네이탈 시각을 미세 조정하며 차트가 어떻게 달라지는지 볼 수 있습니다.
*   **현재 시각**: 조절한 시각을 지금 이 순간으로 되돌립니다.
*   상단 아이콘: **목록으로 돌아가기**, **신규 내담자 등록**.

<br>

### 4. 차트 화면 — 트랜짓 (T)

<img src="/assets/images/Contents/app-usages/R_transit.png" width="250" style="display: block; margin: 0 auto; border-radius: 15px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);">
<br>

**주요 기능:**
*   상단의 **N / T** 토글에서 **T**를 선택하면 안쪽 고리에 네이탈, 바깥 고리에 트랜짓이 겹쳐진 **2링 차트**가 나타납니다.
*   아래 시간 조절 버튼은 이제 **트랜짓 시각**을 움직입니다. 특정 날짜의 트랜짓을 보려면 연/월/일을 조절하거나 **현재 시각**으로 지금 하늘을 불러옵니다.

<br>
